# 架构决策与规范落地

> 本文回答两件事：**这套骨架为什么这么搭**，以及**参考规范的每一条落在了哪个文件**。
> 上游规范：`D:\__projects__\UAV-area-search-DQN\docs\工程架构与组织规范.md`（下称「规范」，§N 指其小节）。

---

## 0. 总纲：四条隔离

> **代码靠「包」隔离，产物靠「一个名字」隔离，参数靠「文件头一处」隔离，日志靠「行前缀」隔离。**

| 隔离维度 | 手段 | 本项目落地 | 解决的混乱 |
|---|---|---|---|
| 代码 | 一算法一包，包内固定六件套 | `algos/madqn/` | 文件散落根目录、找不到某算法的环境 |
| 产物 | 唯一命名源 `name` + 两级目录 | `config.py:name` → `runs/<name>/` | 模型/图/日志混在根目录 |
| 参数 | 文件头集中 + 前缀分作用域 + 启动校验 | `config.py` | 超参散在各函数、改漏、无法复现 |
| 日志 | 固定行前缀契约 | `rlinfra/logger.py` | 日志只能人读、无法脚本诊断 |

## 1. 相对规范做的三处**主动改进**（不是照抄）

### 1.1 隐式「类重绑定」→ 显式链路注册表（规范 §5.3 / §8.2）

规范里用 `MADroneSearchEnv = ExpertMADroneSearchEnv` 做零侵入切换，代价是**孪生符号静默跑错链路**
（import 成功、跑完不报错、照样出模型和数字）。本项目改成 `rlinfra/registry.py` 的**显式登记表**：

- 链路必须在 `AlgoSpec` 里登记，`get_algo()` 取不到就**立刻抛错**；
- 类名对不上时抛出的错误里**直接点名**是 registry 与 algos 不一致；
- 训练开头打一行 `链路标识 | test_mode=... | 类名 | 地图 | 动作 | 设备 | 并行`（规范 §8.2 要求的显式身份行）。

### 1.2 模块级全局变量 → dataclass + 启动校验 + 派生量自证（规范 §5.1 / §8.4）

规范 §8.4 的真实事故：`episodes` 5000→1000 让测试覆盖率从 **92.4% 掉到 8.7%**
（探索衰减与步数上限按 `episodes` 比例绑定，缩短总轮次会同时压缩两者）。
本项目：

- `Config` 是 dataclass，`validate()` 在 `main()` 里**启动即拦**（如「预热回合 ≥ 总轮次」直接报错）；
- **派生量**（`obs_dim`、`eps` 衰减终点、里程碑阈值、产物目录）由 `_derive()` 算出，
  并作为 `派生量自证` 块打进日志 —— 算出来的数必须能核对。

### 1.3 训练主循环拆线程的**理由写进代码注释**

规范 §8.1 承认 `main.py` 膨胀到 4171 行。本项目把「训练主循环」「后台 rollout 线程」「评估」都放
`madqn_trainer.py`（trainer 角色），`main.py` **只留 dispatch**（<120 行）。

## 3. 值得单独说的两个设计

### 3.1 「日志契约 ↔ 诊断脚本」互证是**冒烟自检的必选项**

规范要求「配一个日志解析脚本」，但没要求**验证脚本与日志还对不对得上**。
日志格式一旦漂移，诊断脚本会**静默少解析**（报告看着正常，其实缺字段）——
这是最阴的一类失效。所以 `smoke_test.py` 第⑦项：
用真 logger 造一份日志 → 用 `analyze_training_log.analyze()` 解析 → **逐字段断言**
（EP/TRAIN/REWARD/BEST/ENV/TEST/RES 全查）。

### 3.2 奖励分量命名对齐诊断规则
诊断脚本的启发式规则会找 `milestone*` 与 `stagnation_penalty` / `repeat_penalty`
（规范 §4 的「溯源三问」）。所以本项目的分量名**刻意**取：

```
new_cell_base  repeat_penalty  obstacle_penalty  collision_penalty
step_penalty   target_bonus    stagnation_penalty
milestone_50   milestone_75    milestone_90
```

—— 命名不是为了好看，是为了**能被规则命中**：`milestone_*` 全 0 = 里程碑从未触达；
负分量挤进前三 = 惩罚淹没探索。

### 3.3 「选最优模型」的判据必须**等于部署时的判据**（`GreedyProbe`）

本项目**实测踩出来的最大的一个坑**，值得单列。

**事故现场**（首次 300 回合运行 `runs/demo_300`）：

| 判据 | 结果 |
|---|---|
| 训练回合里挑出的 best（日志写着 90.5%） | 该模型 `--mode test` 实测 **53.9%** |

**差 36 个点。** 三个原因叠加，前两个是主因：

1. 🔴 **判据与产物对不上**：训练回合的覆盖率是 **rollout 权重副本**（actor 线程持有）跑出来的，
   而 `save()` 存的却是 **online 权重** —— **用 A 的表现挑 B**。两者每轮只同步一次，本来就不同。
2. **max 选择偏差**：在 300 个**单回合样本**里挑最大值，挑中的多半是「运气好的一回合」，不是「最好的模型」。
3. ε-greedy 探索红利（次要，且方向不固定：实测同一阶段里 +14 点与 −30 点都出现过）。

**解法**：best 判据改成 `madqn_trainer.GreedyProbe`
—— 每 `MADQN_eval_interval`（默认 25）回合，用 **online 权重**、在**固定地图**上、
按**部署时会用的贪心策略**跑一回合，按这个结果存 best。

**修复后实测**（`runs/demo_probe`，同样 300 回合）：

```
贪心评估 ep75 ：覆盖率 86.34%（训练回合覆盖 56.70%）
贪心评估 ep225：覆盖率 90.21% | 成功 True      ← best 存这里
贪心评估 ep300：覆盖率 90.21% | 成功 True
--mode test   ：覆盖率 90.21% | 成功率 100.00%  ← 与 best 记录**完全一致**
```

日志里同时打印 **「探索红利 = 训练回合覆盖 − 贪心覆盖」**：
**这个差值本身就是一个诊断量 —— 它越大，训练端数字越不可信。**

> 迁移建议：任何 RL 项目在写「保存最优模型」之前先问一句
> ——「**评估时我用的是哪个网络、哪个策略、哪张地图？**」
> 三者只要有一个对不上，你挑出来的 best 就不是 best。

### 3.4 产物清理：序号单调递增 + 边界写死 + 单独自检

长跑必须清理中间 checkpoint（2000 回合实测堆了 40 个 `final_*.pth`），但**清理本身是个危险动作**。
`rlinfra/paths.py` 的 `prune_final_models()` 定了三条边界：

| 约束 | 内容 | 为什么 |
|---|---|---|
| 只在**本实验目录**内 | `listdir(self.root)`，不递归、不跨目录 | 防止误删别的实验/别的地方 |
| 只匹配**精确文件名模式** | 正则 `^<algo>_final_(\d+)\.pth$` | `best` / `final`(无序号) / `pretrain` / 别的算法的文件天然不匹配 |
| 序号**单调递增（max+1）** | 新存的永远是最大号 | 见下 |

🔴 **最后一条是本项目实测踩出来的 bug**：最初 `next_final_model()` 找「第一个空号」，
而清理按序号从小到大删 —— 清理删掉 `final_1` 后空号又变成 1，
于是「存 `final_1` → 它是最小号 → 立刻被删」**无限循环，最新存档全部丢失**。
改成「已有最大序号 + 1」后，新存的永远落在保留区。

**配套规矩**：删文件的逻辑**必须**有一条只属于它的冒烟检查（`utils/smoke_test.py` 第⑨项），
断言「该删的删了、不该删的一个没少」。只测 happy path 会漏掉这一整类错误。

## 4. 诚实代价（别当 bug 修）

| 代价 | 来源 | 缓解 |
|---|---|---|
| rollout 权重副本 → 策略滞后 | 让 actor/learner 线程不共享可变权重 | 同步粒度 = 每轮学习后一次；要更快可改 `request_sync` 频率 |
| `runs/` 不进 git | 产物不该污染版本控制 | 归档 = 打包一个目录；对比 = diff 两个目录 |
| 只有一个算法包，没抽基类 | 先照抄后重构（规范 §8.3 的教训是过早复制） | 复制第二个包时再抽 `base_env` / `base_agent` |
| `mp` 多进程在受限沙箱可能被禁 | `mp.Queue` 走命名管道（规范 §8.7） | `parallel=False` 默认关闭，且是 CI/冒烟的必经路径 |
| 评估图英文标签 | 中文字体缺失会变方框 | `plot_metrics.py --lang cn` 自选 |
