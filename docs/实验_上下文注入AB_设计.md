# 实验设计 · 上下文注入 A/B（把「感觉水平下降」变成可证伪的量）

> 起因（2026-09-30）：用户口述"前些日子使用［DSH／模型］时就感觉水平下降，但是不知道是什么原因"。
> **这是一个真问题，而且比任何教程实验都值钱** —— 问题是他自己提出的、可复现、可观测。
> 本文档只做一件事：把"感觉"翻译成 **自变量 / 因变量 / 固定项 / 判据**。

## 0. 为什么这件事值得做（而不是再做一遍 LoRA）

招聘 JD（Agent Harness 团队 · 深度学习研究员）把「**上下文管理**」列为第一条前沿创新方向，技术栈里点名

所以本实验的目标不是"跑出一个好结果"，而是产出一条**「观察 → 假设 → 测量 → 结论（含证伪）」的完整记录**。
**这条记录本身就是交付物。**

## 1. 假设池（先穷举，再挑一个做）

「水平下降」是一个**观察**，不是一个**假设**。下列六条互相独立，不能混着测。

| # | 假设 | 机制 | 可测性 |
|---|---|---|---|
| **H1** | **长上下文稀释**：上下文占用上升 → 有效注意力衰减 → 同任务成功率下降 | 注意力对中段信息利用不足 | ✅ **本机可测**（`scripts/eval_set.py --context-pad N`，已实现） |
| **H2** | **指令竞争**：全局 `AGENTS.md` + 工作区 `AGENTS.md` + 项目 `AGENTS.md` + 技能层层叠加，约束互相稀释 | 约束条数 ↑ → 单条约束的遵守率 ↓ | ✅ 本机可测（本文档 §2 设计） |
| **H3** | **工具/技能膨胀**：可选项变多 → 选错工具率上升 | 决策空间变大 | ✅ 本机可测（同 H2 的做法，换自变量） |
| **H4** | **服务端模型或版本变化** | 权重/解码参数/系统提示被改动 | ❌ **测不了**（黑盒，无观测点）。只能做弱证据：固定提示词跨日期留档 |
| **H5** | **缓存/前缀变化**导致行为跳变 | KV 前缀命中与否改变输出分布 | ❌ 测不了（同上） |
| **H6** | **基线漂移**：用户自己标准提高了，模型没变 | 无（观察者效应） | ⚠️ 难自证。必须靠 H4 那种**跨期固定留档**才可能反驳 |

🔴 **口径收窄**：H4/H5 **我（AI）观测不到 DSH 服务端**，所以任何"是版本变了"的说法都是**未取证**的。只能把 H1/H2/H3/H6 当成可做的工作，并在报告里**明确写出剩下两条无法排除**。

## 2. 第一个实验：H2 指令竞争（最便宜，一天）

### 2.1 可证伪的假设（写成一句话，必须能被数字打死）

> **H2**：在**同一条任务、同一个模型、同一天**的前提下，把注入的常驻约束从「三层规则 + 全部技能」
> 降到「只有项目级规则」，任务通过率**上升 ≥ 15 个百分点**。
> **若上升 < 5 个百分点 ⇒ H2 不成立，撤回。**

### 2.2 变量

| 项 | 内容 |
|---|---|
| **自变量** | 注入档位 A / B / C（见下表） |
| **因变量** | ①通过率（主）②平均轮数 ③工具选错次数（次） |
| **固定项** | 同一批任务、同一天内跑完、同一模型、**同一台机器**、`temperature` 不动、每档 ≥ 5 次重复 |
| **样本量** | 任务 × 重复 ≥ 30 次/档。**低于这个数不要下结论**（参见 `docs/实验登记表.md` §一结论 1：换一个 seed 就有 13 个百分点的差） |

| 档 | 注入内容 | 用途 |
|---|---|---|
| **A（全量）** | 全局 `~/.dsh/AGENTS.md` + 工作区 `AGENTS.md` + 项目 `AGENTS.md` + 全部技能 | 复现"水平下降"的现场 |
| **B（中间）** | 只留工作区 + 项目 `AGENTS.md`，关掉技能 | 定位是"规则"还是"技能"在竞争 |
| **C（最小）** | 只留项目 `AGENTS.md` | 下界 |

> ⚠️ A 是**现状**，不是"坏档"。A 里的规则每一条都有自己的理由 —— 本实验要回答的是
> 「**叠加起来**有没有副作用」，不是「哪条规则是错的」。

### 2.3 任务集（必须能自动判对错）

复用 `scripts/eval_set.py` 的**判分器思路**（`v_exact_int` / `v_boxed` / `v_bare_number` /
`v_tool_json`），但任务换成**Agent 编码任务**（DSH 自己跑）：

| id | 任务 | 判分（确定性） |
|---|---|---|
| a1 | 在指定文件追加一行，内容严格为 `OK` | 文件内容精确匹配 |
| a2 | 修一个故意写错的函数，使给定测试通过 | 跑测试，退出码 0 |
| a3 | 从 3 个文件里找出一处不一致，只报告文件名 | 文件名精确匹配 |
| a4 | 按给定 JSON schema 输出一个 tool call | JSON 解析 + 键校验（**禁止型约束**） |
| a5 | 读一个长日志，只回答其中一个字段值 | 值精确匹配（**长上下文 + 禁止型**） |

🔴 每条的判分器必须是**确定性**的：同一份产出永远给同样的分。不许用"看起来对不对"。

### 2.4 记录契约（复用现有观测平台）

每跑一次写一行，格式与 `metrics.jsonl` 一致：
```json
{"ts": ..., "step": N, "name": "ab/<档>/<task_id>/pass", "value": 1.0}
{"ts": ..., "step": N, "name": "ab/<档>/n_turns", "value": 7.0}
```
跑完落 `runs/obs/ab_<档>/{metrics.jsonl,run.json}`，**并回填 `docs/实验登记表.md`**。

### 2.5 判据（先把"什么算赢"写死，再跑）

| 结果 | 判定 |
|---|---|
| C 比 A 高 ≥ 15 个百分点 | ✅ **H2 成立**，且效应量大到值得当成一个结论 |
| C 比 A 高 5–15 个百分点 | ⚠️ **方向成立、效应量不确定**，需加样本再来一轮 |
| C 比 A 高 < 5 个百分点 | ❌ **H2 不成立**，撤回；转 H3（工具膨胀）或 H1 |
| C 比 A **更低** | 🔴 **反向**——说明常驻规则是**净收益**，"水平下降"另有原因，转 H1/H6 |

## 3. 顺带能做的：H1 的长上下文版本（已验证可执行）

`scripts/eval_set.py` 已内置 `--context-pad N`（在题目前塞 N token 无关填充，针藏在里面）。
一旦高算上有可用的模型目录，**当天就能出第一条曲线**：

```bash
# 基座 · 无填充（基线）
python scripts/eval_set.py --tag base_pad0
# 基座 · 塞 4k / 8k / 16k
python scripts/eval_set.py --tag base_pad4k  --context-pad 4000
python scripts/eval_set.py --tag base_pad8k  --context-pad 8000
python scripts/eval_set.py --tag base_pad16k --context-pad 16000
# 微调后（adapter 路径来自 lora_smoke 的产物）
python scripts/eval_set.py --tag lora_pad0 --adapter <run_dir>/adapter
```

**要看的东西**：`eval/needle/acc` 随 pad 增大是否下降，以及 `eval/constraint/acc`（禁止型）
**是否比** `eval/format/acc`（要求型）**掉得更快**。
> 后者若成立，就与检索到的 arXiv:2604.20911（Omission Constraints Decay / Commission Constraints Persist）
> 形成**独立复现** —— 那是可以拿去讲的东西。

## 4. 诚实短板（不许省略）

1. **H4/H5 无法排除**。DSH 服务端是黑盒，我没有任何观测点。若实验当天服务端正好变了，所有结论都受污染。
   **缓解**：① 所有档位**同一天内跑完**；② 记录当天日期与模型标识；③ 结果只当"当日快照"，不做跨月比较。
2. **样本量是新手的头号杀手**。`docs/实验登记表.md` §一 已实测：**只换 seed，best 覆盖率差 13.14 个百分点**。
   ⇒ 每档 n < 30 时，"C 比 A 高 10 个百分点"很可能是噪声。
3. **人肉跑 = 不可复现**。A/B/C 若靠手工开三次会话，就没有可比性。**必须脚本化**（或至少固定 prompt 文本、逐字复制）。
4. **H6（基线漂移）不可自证**。我能想到的唯一缓解是 H4 的跨期留档 —— 但那要**今天就开始存**，否则以后无从对照。
   **⇒ 这是一条"现在不做、以后永远做不了"的事**：从今天起，每次觉得"变差了"就存一份固定提示词的输出快照到 `runs/obs/snapshots/<日期>/`。
5. **本文档尚未跑过任何一次实验**，所有数字都是待测的。
